# Баланс первичного рынка Москвы по классам

Рабочий расчет на **27 октября 2026 года**: запуски, продажи, вводы, строительный портфель, текущая распроданность и непроданный остаток до 2030 года. Группы: эконом/комфорт, бизнес, элитный класс. Площади — **тыс. м²**, распроданность — доля от 0 до 1.

**[Открыть технический Excel](moscow_market_technical.xlsx)** · **[Методика и допущения](METHODOLOGY.md)** · **[Результаты CSV](reference_results/forecast_by_class.csv)**

## Воспроизведение

Python 3.10+, внешние зависимости не нужны:

```bash
python portfolio_forecast/model.py
```

Результат появится в `portfolio_forecast/results/forecast_by_class.csv`. Для другого снимка:

```bash
python portfolio_forecast/model.py --input-json path/to/snapshot.json --output-dir path/to/results
```

В [снимке входов](inputs/snapshot_2026-10-27.json) сохранены агрегированные площади и проданные метры по классам и годам ввода, историческая калибровка и рабочие параметры. Полная матрица проектов для запуска не нужна. Источники: матрица `2026-10-23-project_data(1).xlsx` и лист «запуски-портфель» файла «Продажи и ипотека.xlsx».

В Excel лист **«Прогноз»** содержит шесть показателей по классам и общий итог. На листе **«Допущения»** изменяются продажи, переносы, структура запусков и профили ввода. **«Расчет»** показывает годовые балансы, **«Когорты»** — распределение продаж и выбытие площадей по годам ввода, **«Данные»** — источники и ограничения.

## Статус расчета

Запуски и вводы соответствуют согласованной рабочей траектории. Продажи по классам распределяются по методу [sales_decomposition](../sales_decomposition/README.md).

Распроданность и непроданный остаток — новая техническая оценка с явно заданными допущениями: общими для классов весами продаж по срокам ввода и равномерными продажами IV квартала для оценки остатка 2026 года. Это не копия предыдущего расчета из отдельного диалога. Вводы и непроданное предложение из этого раздела пока автоматически не подключены к модели цен.

Проверено: балансы площадей, сумма продаж классов, ограничения проданной площади, отсутствие нераспределенных продаж в рабочем сценарии; результаты Python сопоставлены с формульным Excel с точностью лучше 0,000001 тыс. м². Проверена реакция Excel на изменение прогноза продаж. Проверка выполнена в расчетном движке генератора; отдельный запуск в настольном Excel/Astra не проводился.

# Независимое восстановление кеша и рассрочки по РФ

Срез расчёта — 3 ноября 2026 года, факт — январь 2021 — сентябрь 2026. Это самостоятельная проверка исторического расчёта по РФ; она не заменяет существующую модель Москвы в соседних папках.

**Начать с [разбора результатов](report.md).** Для просмотра устанавливать Python не требуется: CSV открываются на GitHub и в Excel.

| Что посмотреть | Файл |
|---|---|
| Помесячные входы и расчёт остатка | [current_monthly.csv](current_monthly.csv) |
| Квартальные результаты и MA5 | [current_quarterly.csv](current_quarterly.csv) |
| Эффект известных исправлений | [corrections_impact.csv](corrections_impact.csv) |
| ARIMAX с AR(1)-ошибками, разные даты обучения | [model_sensitivity_ARIMA.csv](model_sensitivity_ARIMA.csv) |
| Буквальное уравнение с лагом объёма, разные варианты подготовки | [model_sensitivity_OLS.csv](model_sensitivity_OLS.csv) |

## Что рассчитано

1. Чистые продажи жилых помещений: покупки минус расторжения, по РФ.
2. Ипотечные выдачи ДДУ ЦБ пересчитаны в полную стоимость сделок через фактический ПВ льготных программ ДОМ.РФ.
3. Остаток продаж переведён в площадь по средней месячной цене.
4. Месячные площади сложены в кварталы, затем сглажены MA5.
5. Независимо оценены две разные спецификации: регрессия с лагом объёма и регрессия с AR(1)-ошибками.

Отрицательные остатки сохранены. Разделения кеша и рассрочки друг от друга нет. Сравнение «до исправлений» восстанавливает только изменения из сохранённого журнала базы; это не подтверждённая полная версия старой модели. Будущий сценарный прогноз в этой папке не строится.

## Запуск на сохранённых данных

Python 3.12; команды из корня репозитория:

```sh
python -m pip install -r cash_installments/rf_reconstruction_20261103/requirements.txt
python cash_installments/rf_reconstruction_20261103/run.py
```

Запуск пересоздаёт CSV результатов в этой папке и проверяет их по сохранённым значениям. Доступ к Supabase и исходным XLSX не нужен.

- `sales_monthly.json` — сохранённые месячные агрегаты продаж Supabase.
- `mortgage_inputs.csv` — месячные выдачи ДДУ, млн руб., и ПВ, проценты, извлечённые из предоставленных XLSX; даты выдач ЦБ уже сдвинуты с отчётной даты на предыдущий месяц.
- `keyrate.csv` — историческая ставка ЦБ по рабочим датам; квартальная ставка усредняется по календарным дням.
- `rebuild.py` — воспроизведение подготовки ряда и известных исправлений.
- `fit.py` — МНК и точное гауссово ML для стационарной AR(1)-ошибки, реализованное через профиль правдоподобия.
- `export_sales.sql` — запрос для получения месячных агрегатов при отдельном авторизованном обновлении базы.

Это фиксированный срез, а не автоматическое обновление. Для обновления нужны новые агрегаты продаж, выдачи ДДУ и ПВ, согласованные по месяцам. Полные источники, допущения, единицы и ограничения описаны в [отчёте](report.md).

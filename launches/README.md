# Запуски новых проектов в Москве

Код краткосрочной модели и сценария восстановления запусков до 2030 года. Все площади во входных данных и результатах задаются в **тыс. м² жилой площади**. Python 3.10+, зависимость — NumPy.

Реальные входные данные и результаты этого блока хранятся локально. В репозиторий включён синтетический пример для проверки установки; его результаты нельзя интерпретировать как прогноз рынка.

## Запуск

Из корня репозитория:

```bash
python -m pip install -r launches/requirements.txt
python launches/model.py --input-json /path/to/local_snapshot.json
```

Результат печатается в терминале и сохраняется в `launches/results/forecast.json`. Папка результатов исключена из Git. Если не указан `--input-json`, программа ищет локальный `launches/data/snapshot_2026-10-22.json` и сообщает об ошибке, если файла нет.

Синтетический пример:

```bash
python launches/model.py --input-json launches/examples/synthetic_input.json
```

Параметры сценария и отдельный выходной файл:

```bash
python launches/model.py --input-json /path/to/local_snapshot.json --adjustment 0.25 --anticipation 0.5 --output-json launches/results/slow.json
python launches/model.py --input-json /path/to/local_snapshot.json --ratio 0.93 --output-json launches/results/low_ratio.json
```

Стандартные пути определяются относительно скрипта; явно переданные относительные пути — относительно текущей папки терминала.

## Методология

Для остатка 2026 года используется квартальная регрессия:

$$\Delta_4 L_t=c+\rho\Delta_4 L_{t-1}+\beta\Delta_4 S_{t-1}.$$

Здесь $L$ — запуски, $S$ — все продажи, $\Delta_4 X_t=X_t-X_{t-4}$. Параметры оцениваются методом наименьших квадратов. Доступный факт сохраняется. Историческая проверка: восемь первых пригодных наблюдений для первоначальной оценки, затем последовательные прогнозы до II квартала 2026 года с расширением истории. При включении новых фактов последняя оценка параметров может использовать более позднюю историю, чем исходная проверка.

Длинная рекурсия статистического блока может давать отрицательные квартальные объёмы. Такие годы помечаются `statistical_launches: null`, исходные оценки сохраняются в `raw_statistical_annual_sum` и `invalid_statistical_quarters`. Отрицательные значения не обрезаются до нуля. Для года, задающего начальный уровень сценария, отрицательный квартальный прогноз вызывает ошибку.

С 2027 года используется годовая подстройка к ожидаемому спросу:

$$L_t=(1-\lambda)L_{t-1}+\lambda k[(1-\theta)S_t+\theta S_{t+1}].$$

Здесь $t$ — год. Начальный уровень — факт запусков за девять месяцев 2026 года плюс статистическая оценка IV квартала.

| Параметр | По умолчанию | Смысл |
|---|---:|---|
| `--adjustment`, $\lambda$ | 0,5 | За год проходит половина расстояния до целевого объёма |
| `--anticipation`, $\theta$ | 0,5 | Равные веса продаж текущего и следующего года |
| `--ratio`, $k$ | Из истории | Среднее годовых отношений запусков к продажам за 2023–2025 годы |

Веса 0,5 — **экспертные допущения**, а не статистически оценённые коэффициенты. Отношение $k$ — исторический ориентир, а не доказанная норма восполнения запасов. Продажи следующего года за границей горизонта принимаются равными последнему прогнозному году. Поле `anticipation_effect` показывает разницу со сценарием без учёта будущего спроса.

Долгосрочный блок является сценарием; его независимая точность пока не оценена. Непроданные остатки, вводы и РНС в расчёт запусков пока не включены.

## Подготовка локального файла

Используйте структуру [examples/synthetic_input.json](examples/synthetic_input.json), заменив демонстрационные значения своими данными:

- `units`: `thousand square metres`.
- `quarterly`: непрерывная история с ключами вида `2025Q1` и числовыми полями `launch` и `sales`. История запусков начинается с 2020 года, продаж — с 2021-го; текущая версия рассчитана на факт до III квартала 2026 года.
- `annual_sales_forecast`: прогноз **всех** продаж, включая ипотеку, кеш/рассрочку и one-off, с ключами `2026`–`2030`.
- `source_notes`: источники, даты, единицы и допущения восстановления данных.

Запуск кеш-модели не обновляет этот файл автоматически: кеш — только один канал общего рынка. III квартал запусков можно восстановить из факта за девять месяцев и первых двух кварталов, явно указав округление в источниках.

Для другого прогнозного периода пересмотрите фиксированные окна калибровки, проверки и граничное допущение в коде. Локальные снимки `launches/data/*.json` исключены из Git.

## Проверки

```bash
python -m unittest discover -s launches/tests -v
```

Проверяются расчёт на синтетической истории, граничные сценарии, недопустимые веса и запуск из другой рабочей папки.

## Как понимать результат

- Уверенное сопоставление — аналитическое соответствие объектов по адресу (включая рабочие варианты номера), квартирности и координатам. Это не юридическая экспертиза договоров.
- Для 3-й Прядильной, 13 учтены три ID по одному РНС: 537 + 170 + 170 = 877 квартир.
- Четыре рабочих варианта адресов (1/1А, 19/19А, 41А/41/1А, 60/60/2) отмечены отдельно. При требовании строго документального мэппинга их нужно сверить по РНС/кадастру; совпадение буквального адреса не заявляется.
- «Совпадение не установлено» означает, что найденный соседний корпус не принят для этой площадки. Это не доказательство отсутствия самой площадки в ЕИСЖС. Для части таких пар выполнена характеристическая проверка по сохранённым данным, без полного чтения разрешительных документов.
- Площадь 355,8 тыс. м² относится только к 23 уверенно сопоставленным корпусам. Спорные ID и соседние корпуса в неё не включены.
- Наличие карточки и проектной декларации в ЕИСЖС фиксируется отдельно от режима эскроу и назначения квартир. Отсутствие эскроу не означает отсутствие в ЕИСЖС.

## Доступ к источникам и воспроизведение

Использованы сохранённые карточки/характеристики перечня и выгрузка ЕИСЖС; адресные названия, состав корпусов и номера ПД дополнительно проверены по индексированным страницам официальных сайтов фонда, ЕИСЖС и стройкомплекса Москвы. Прямое открытие части страниц фонда и ЕИСЖС завершалось тайм-аутом/403. Полные тексты РНС, договоры и выписки в этот этап не загружались. Поэтому основания и расхождения сохранены явно, а документальная верификация всех пар не заявляется.

Машиночитаемый реестр: [review.json](review.json). Повторная сборка отчёта из сохранённых входных данных и явных решений:

```bash
python renovation_analysis/review_spatial_candidates.py
```

Следующий шаг: разобрать два конфликта по РНС/участкам, затем искать остальные площадки по адресу/РНС без ограничения 200 м. Для оценки площади вне ЕИСЖС нужно дополнительно собрать площади квартир по всему перечню.

# Строящиеся объекты реновации: адресный перечень и кандидаты ЕИСЖС

Дата получения: 26.10.2026. Перечень выгружен из публичного набора карты Dolewka.ru, который указывает Фонд реновации источником сведений. Прямой доступ к fr.mos.ru возвращал 503/тайм-аут. В CSV сохранены ссылки на первичные карточки фонда, извлечённые из страниц посредника. Их актуальность и полноту необходимо проверить.

Файлы: construction_sites.csv — все 169 записей одной генерации с координатами, адресами и, где карточки доступны, квартирностью; eis_spatial_candidates.csv — все пары в радиусе 200 м от точек перечня до объектов исходной выгрузки ЕИСЖС от 23.10.2026; construction_map_source.geojson — исходный ответ карты; statistics.json — контрольные количества. CSV UTF-8 BOM, разделитель ;.

Открыть index.html браузером для просмотра таблицы и первичных ссылок без дополнительного ПО.

ВАЖНО: близость координат — только способ отбора кандидатов. Соседний коммерческий ЖК не следует считать объектом реновации. Совпадение квартирности — дополнительный, но не окончательный признак. Проверять РНС, кадастровый участок, адресные изменения, корпуса. Несколько строк карты могут относиться к одному объекту ЕИСЖС, а одна площадка — к нескольким ID. Не складывать площади кандидатов и не вычислять на этих парах долю вне 214-ФЗ. Объект не найден в радиусе 200 м — не означает отсутствие ПД или строительство вне 214-ФЗ.

Значения 166 на старых кэшированных страницах относятся к другой дате/генерации. Здесь использована одна генерация 20261026T012210Z-58d44c16c3d1 на 169 уникальных site_id. Полнота этого набора относительно всей программы реновации независимо не подтверждена. Стадии карты на 26.10.2026 и ЕИСЖС на 23.10.2026 могут различаться.

Границы площадей: в карте нет площади квартир для всех объектов. Поэтому пока можно строить адресный реестр, но нельзя рассчитывать долю программы по площади из количества площадок.

# Москва: реновация, ЕИСЖС и крупные покупки жилья

Пакет передачи исследования другому аналитику. Собран 26.10.2026.
Последний срез объектов — 23.10.2026. Продажи — январь 2021 — сентябрь 2026.

## С чего начать

1. Откройте `START_HERE.html` обычным браузером: там есть ссылки на материалы.
2. Прочитайте `docs/RESEARCH_HANDOVER.md`: вопросы исследования, результаты, пересмотренные выводы и следующие шаги.
3. Откройте `results/moscow_renovation_screening.xlsx` в Excel или LibreOffice. Листы: «Итоги», «Кандидаты», «История».
4. Для проверки вычислений запустите `python code/reproduce.py` из распакованной папки. В Windows команда также может называться `py` или `python3`. Нужен Python 3.10 или новее; дополнительные пакеты не нужны.
5. Результат появится в `reproduced/`: 38 записей по 37 корпусам и воспроизведённая рабочая годовая доля. Это воспроизведение на сохранённой выборке, а не новый поиск по всей Москве.

## Что находится в архиве

- `data/2026-10-23-project_data.xlsx` — исходная выгрузка 2680 объектов, без изменений.
- `results/moscow_renovation_screening.xlsx` — ранее подготовленный реестр проверки, без изменений.
- `data/projects_flat.csv` — плоское представление исходной выгрузки.
- `data/candidates_register.csv` — содержимое реестра 37 корпусов, включая причины и URL.
- `data/monthly_selected.csv` — 746 месячных записей по 37 корпусам из сохранённого реестра.
- `data/working_purchases_21.csv` — отдельный список 21 объекта для рабочей оценки покупок для реновации; это не список документально подтверждённых покупателей.
- `data/moscow_net_annual.csv` — сохранённые общерыночные знаменатели годовой доли.
- `data/fund_as_developer.csv` — 28 объектов фонда как застройщика. Их продажи нельзя автоматически считать покупками фонда.
- `data/ac_portfolio_provisional.csv` — прежние рабочие значения из обсуждения отчётов АЦ, с предупреждением о непроверенной сопоставимости.
- `docs/SOURCES.csv` — обычные веб-ссылки, которые работают без ChatGPT; также ссылки сохранены в реестре.
- `docs/RESEARCH_HANDOVER.md` и `docs/CONTINUE_CHECKLIST.md` — аналитическая передача и конкретные задачи.
- `code/` — переносимый код чтения XLSX, отбора, воспроизведения долей и проверки пакета.
- `queries/` — SQL для самостоятельного обновления данных через собственное разрешённое подключение к исходной базе.
- `MANIFEST_SHA256.csv` — контрольные суммы файлов.

CSV записаны в UTF-8 с BOM, разделитель `;`, десятичная точка. Даты нормализованных CSV имеют формат YYYY-MM-DD. В буквальном экспорте `candidates_register.csv` даты могут оставаться числами Excel: нормализованные даты находятся в `monthly_selected.csv` и результатах `reproduce.py`.

## Что нужно знать до использования

**Рабочие 6,1% за январь–сентябрь 2026 года — не окончательно установленная доля фонда.** По части объектов подтверждено назначение для реновации, но покупатель пакетной сделки установлен косвенно. Эти объёмы нельзя автоматически вычитать как доказанные покупки фонда.

Покупки фонда, продажи самим фондом, бесплатное предоставление квартир переселенцам и оптовые покупки иных организаций — разные события. Остаток продаж после исключения выявленных пакетов не тождественен частному спросу.

В архиве нет полного помесячного рынка Москвы: сохранена история только 37 отобранных корпусов и общерыночные годовые агрегаты. Первичная таблица 375 крупных записей не сохранилась отдельным файлом; её можно заново получить из полной выгрузки по SQL. Нет полного экспорта переписки и полных копий просмотренных веб-страниц/отчётов АЦ. Аналитическая логика и существенные поправки восстановлены в записке; источники, которые нужно получить заново, перечислены явно.

Код `reproduce.py` подготовлен для передачи и проверен на сохранённых данных. Он воспроизводит правило отбора, но не является оригинальным временным кодом создания оформленного Excel. Создание XLSX не требуется для продолжения анализа: исходные XLSX, CSV и воспроизводимые результаты уже включены.

Архив самодостаточен для просмотра и воспроизведения сохранённой выборки. Интернет и доступ к исходной базе нужны только для новых документов и обновления всего рынка.

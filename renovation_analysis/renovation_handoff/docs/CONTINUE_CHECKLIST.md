# Следующие шаги для аналитика

## Приоритет 1. Проверить покупателя новых пакетов

Начать с ID 45973, 61422, 58064, 43134, 30548. Открыть строку в реестре и карточку ЕИСЖС. Получить декларацию до скачка, декларацию со скачком и следующую. Сверить накопленные площади, число договоров и квартир, изменения состава проекта. Если данные раскрывают число договоров с физическими/юридическими лицами, использовать его как дополнительный признак; юридическое лицо ещё не означает фонд.

По возможности получить подтверждение покупателя через выписку/договор/официальное раскрытие. Вести отдельно: объект программы; покупатель; купленный объём; дата регистрации; месяц попадания в статистику; источник и страница; степень уверенности. Текущего названия ЖК недостаточно.

## Приоритет 2. Закрыть проблемы учёта

- ID 45258: объяснить превышение исторических покупок над текущей площадью корпуса.
- ID 40156: подтвердить, что взаимопогашение покупки и расторжения корректно отражено в чистой серии.
- ID 43185, 51189, 51190, 51191, 54981, 63448, 64340: проверить первые записи, пропуски и даты публикации, не распределять объём по месяцам без оснований.
- ID 38951 и 46278: до скачка долго нет продаж; это не доказывает ни оптовую сделку, ни накопленную запись.

## Приоритет 3. Подтвердить прежнюю рабочую группу

Проверить 21 строку `working_purchases_21.csv`. Получить документы с покупателем и объёмом. Передача дома по программе и покупка фондом по конкретному ДДУ — не одно доказательство. Не удалять ID 60987 из прежней группы только из-за фильтра размера.

## Приоритет 4. Расширить поиск и проверить полноту

Получить весь месячный ряд Москвы, выполнить `queries/export_moscow_sales.sql` и запустить:

    python code/reproduce.py --sales /путь/к/полной_выгрузке.csv --output /путь/к/новому_результату

Исходный фильтр пропускает небольшие покупки и приобретения частями. Сопоставить чувствительность порогов 20/30/50% и 3/5/10 тыс. м², отдельно проверять несколько последовательных месяцев. Класс использовать для очередности проверки, а не исключения бизнес-класса.

## Приоритет 5. Вернуться к охвату строительного портфеля

Найти оригиналы старых отчётов АЦ Москвы, зафиксировать точные определения и страницы. Сопоставить перечни объектов на одинаковые даты; определить пересечение площадей. Запросить методологию составителя, если перечень отдельного блока недоступен. До этого не складывать обе серии как непересекающиеся.

## Итоговый стандарт результата

Публиковать три отдельные величины: подтверждённые покупки фонда; вероятные покупки для реновации; остальные неидентифицированные оптовые записи. Для очищенного спроса давать чувствительность к включению вероятных покупок и сохранять исходную серию рядом. Изменения методологии документировать, а не перезаписывать прежние версии без следа.

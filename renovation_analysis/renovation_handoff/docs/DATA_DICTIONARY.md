# Словарь и происхождение данных

В `monthly_selected.csv`:
- building — ID объекта ЕИСЖС, строковый ключ.
- period — месяц наблюдения в базе, не дата договора.
- res_bought_m2 / res_bought_qty / res_bought_rub — месячные покупки из prodoma.sales.
- res_cancel_m2 — месячные расторжения из той же таблицы.
- property_class — класс из сохранённого реестра; при обновлении предпочтительно брать класс из новой выгрузки.

В исходной XLSX:
- Корпус — ID ЕИСЖС, не строительный/маркетинговый корпус.
- Жилая площадь — используемая в исследовании площадь квартир на дату среза.
- Общая площадь — другое поле, не заменять им площадь квартир при расчёте доли пакета.
- Статус корпуса — текущий статус среза, не историческая временная серия.
- Дата публикации проекта и даты ПД — числа дат Excel; начало эпохи 1899-12-30.
- Количество проданных квартир по проекту, шт. — семантика требует проверки: в пакетных объектах встречается 1 при сотнях квартир. Нельзя автоматически смешивать с квартирностью из monthly_selected.csv.

`candidates_register.csv` — буквальный экспорт значений существующего XLSX; формулы сохранены в XLSX, в CSV — их вычисленные значения. Оригиналы XLSX не изменялись.

`working_purchases_21.csv` — не реестр подтверждённых покупателей. 20 строк восстановлены из сохранённого Excel, одна (60987) — из зафиксированного результата предыдущего запроса. Полной месячной истории 60987 нет в пакете.

`moscow_net_annual.csv` — сохранённые агрегаты prodoma.sales_net. Не вычисляются из monthly_selected.csv: последняя содержит только отобранные корпуса.

`ac_portfolio_provisional.csv` — рабочие заметки, не первичная выгрузка отчётов. Исходные PDF и точные страницы нужно найти заново. Не включать в доказательную базу количественного вывода без проверки.

Статус «покупатель не установлен» не означает, что покупатель — население. Статус «связь с реновацией» не равен приобретению фондом всех квартир.

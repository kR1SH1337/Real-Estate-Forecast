## Основные выводы

Рабочая оценка выявленных покупок для реновации составляет 2,47% чистых продаж Москвы в 2023 году, 2,50% в 2024 году, 2,46% в 2025 году и 6,15% за январь–сентябрь 2026 года. По части объектов назначение для реновации подтверждено, но покупатель конкретного пакета установлен косвенно. Эти доли не являются окончательно доказанной долей покупок фонда.

Передача фонду двух домов подтверждена внешним источником; соответствующие пакеты в базе составляют 69,7 тыс. м². Связь конкретных месячных записей с передачей установлена по характеристикам объектов; договоры и выписки с покупателем в набор не входят.

В адресном перечне 169 строящихся площадок найдены кандидаты ЕИСЖС для 41 площадки в радиусе 200 м и для 27 в радиусе 100 м. Пространственная близость не доказывает совпадение. Первоначальные два сопоставления расширены до 21 площадки / 23 корпусов; подробные решения по всем 69 парам и источники приведены в новом реестре проверки. Исходный архивный файл `new_address_matches.csv` сохраняет первоначальные два сопоставления и не является актуальным полным итогом.

По сообщению пользователя на сайте фонда указано 170 строящихся домов; перечень 169 записей принят как практически полный рабочий адресный набор. Единицы «площадка», «дом» и ID ЕИСЖС не тождественны; объектная сверка с официальным числом 170 ещё не выполнена.

**Доля реновации вне ЕИСЖС/214-ФЗ пока не установлена.** Отсутствие пространственного совпадения не доказывает отсутствие проектной декларации. Складывать портфель ЕИСЖС и отдельный блок реновации без проверки пересечения нельзя.

## Структура и воспроизведение

- [Основной пакет](renovation_handoff/README.md): исходные данные, реестры, графики, Python и SQL.
- [Адресный этап](construction_inventory_20261026/README.md): перечень площадок, координаты, первичные ссылки и ограничения сопоставления.

Для просмотра HTML-таблиц скачайте папку и откройте `renovation_handoff/START_HERE.html` либо `construction_inventory_20261026/index.html` браузером.

Для воспроизведения сохранённой выборки (Python 3.10+, без дополнительных библиотек):

```bash
cd renovation_analysis/renovation_handoff
python code/verify_package.py
python code/reproduce.py
```

Сохранённые исходные пакеты перенесены без изменений. Файл `ac_portfolio_provisional.csv` содержит прежние рабочие значения с неподтверждённой сопоставимостью; они не используются для расчёта суммарного портфеля.

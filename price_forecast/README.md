# Прогноз цен первичного жилья Москвы

> **Целевой сценарий продаж:** по запросу пользователя рассчитаны цены, сохраняющие площади последнего Excel. [Годовые цены и проверка совместимости с фактом 2026](market_state/SALES_TARGETS.md). Это отдельный сценарий с фиксированными продажами; ниже сохранён предыдущий эндогенный расчёт.

**27.10.2026: замкнута обратная связь «цены → ипотечные продажи в метрах → запуски и портфель → цены».** Использованы повышенные ипотечные номиналы из последнего файла пользователя «Продажи и ипотека (1).xlsx». Кеш, рассрочки и one-off заданы отдельно. Коэффициенты ценовой модели сохраняются, годовые ориентиры цен в подборе не используются.

## Согласованный результат

| Год | Реальный рост цен | Номинальный рост цен | Продажи, млн м² | Непроданный остаток на конец года, млн м² |
|---|---:|---:|---:|---:|
| 2026 | **4,75%** | **11,82%** | **2,609** | **7,705** |
| 2027 | **2,38%** | **7,32%** | **2,620** | **6,157** |
| 2028 | **3,93%** | **8,12%** | **2,971** | **5,060** |
| 2029 | **5,00%** | **9,24%** | **3,054** | **4,839** |
| 2030 | **5,04%** | **9,28%** | **2,990** | **5,093** |

Темпы цен — декабрь к декабрю, продажи — полный год. Факт девяти месяцев 2026 сохраняется. Ипотечные объёмы делятся на средние цены соответствующих прогнозных периодов; темп декабря не подставляется вместо среднегодового изменения цены. Индекс переведён в сопоставимую рублёвую цену с опорой на среднюю цену 2025 года из исходного Excel.

![Согласованные цены и продажи](market_state/coupled_results/coupled_forecast.svg)

В исходном новом Excel продажи составляли 2,652 / 2,726 / 3,128 / 3,305 / 3,312 млн м². После пересчёта цены ипотечные метры снижаются. Новый объём продаж повторно передаётся в тот же механизм запусков, вводов и остатка. Рублёвые ипотечные сделки, ПВ и площади кеша/рассрочек с one-off внутри итераций не изменяются.

Цикл сошёлся за 21 итерацию. Другие начальные цены и скорости обновления дали то же численное решение. **Это проверка внутренней согласованности, не подтверждение прогнозной точности:** ограничения исторической оценки ценовой зависимости сохраняются. Привязка индекса к рублёвой цене и месячная разбивка — явные предпосылки; их чувствительность показана отдельно.

## Запуск

Python 3.10+, из корня репозитория:

```bash
python -m pip install -r price_forecast/requirements.txt
python price_forecast/market_state/coupled_forecast.py
```

Агрегированные каналы из Excel включены в `market_state/inputs/channel_forecast_2026-10-27.json`. Полный Excel для запуска не нужен. Согласованные результаты записываются в `market_state/coupled_results/`. Снимок исходного портфеля и его механизм используются как входы; обновлённый баланс сохранён в результатах согласования, а не заменяет исходную версию другого раздела.

Для воспроизведения нового баланса кодом раздела портфеля:

```bash
python portfolio_forecast/model.py --input-json price_forecast/market_state/coupled_results/portfolio_snapshot_equilibrium.json --output-dir /tmp/moscow_equilibrium_portfolio
```

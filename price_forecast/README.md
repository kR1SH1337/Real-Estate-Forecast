# Прогноз цен первичного жилья Москвы

Исследование динамики индекса цен ДОМ.РФ: очистка реального роста от отдельных эпизодов и добавление показателей состояния рынка. Факт — по сентябрь 2026 года; расчёты от 26.10.2026. Основные сравнения представлены в реальных темпах. Текущие статистические варианты не используют целевые годовые темпы для подбора параметров.

## Текущий этап: состояние рынка

В модель с тремя dummy добавлено отношение непроданного строительного портфеля к средним месячным продажам за шесть месяцев. Больший запас относительно продаж снижает прогнозный реальный рост. Также проверены динамика продаж к прошлому году, краткосрочная динамика, другие лаги и сезонность.

Ниже — **условный сценарий сохранения текущего показателя рынка**, а не утверждённый базовый прогноз продаж и предложения. Вариант: обеспеченность продажами с лагом 1, без сезонных контролей.

| Год | Реальный рост цен | Номинальный рост цен |
|---|---:|---:|
| 2026 | 4,70% | 11,77% |
| 2027 | 1,65% | 6,55% |
| 2028 | 1,65% | 5,75% |
| 2029 | 1,65% | 5,75% |
| 2030 | 1,65% | 5,75% |

Темпы — декабрь к декабрю. Фактические девять месяцев 2026 года сохраняются; прогноз начинается от фактического уровня сентября. Новые эпизоды ажиотажа на прогнозе не предполагаются. Дефлятор — ИПЦ РФ из используемого макросценария.

При снижении продаж на 20% и прежнем запасе условный реальный рост 2027 года снижается до 0,58%; при росте продаж на 20% повышается до 2,54%. Это сценарная реакция, не доказанная причинная эластичность. Состояние рынка меняется постепенно за шесть месяцев, затем удерживается; полный баланс продаж и портфеля здесь не рассчитывается.

**Ограничения:** на общей истории из 54 наблюдений модель без показателя рынка даёт 3,09% реального роста в 2027 году, с показателем — 1,65%. Разницу с прежними оценками на 67 наблюдениях нельзя целиком приписывать новому регрессору. Годовой RMSE при добавлении обеспеченности изменился с 11,32 до 11,64 п.п., улучшения точности пока нет. При начале оценки с 2023 года знак коэффициента обеспеченности меняется. Поэтому этот вариант остаётся экспериментом.

## Очистка истории

Реальный месячный рост разделён на фоновую авторегрессию и три отдельных эффекта:

1. Ипотечные эпизоды до 2025 года: ранняя разметка остаётся предварительной.
2. Сентябрь 2025 — январь 2026, июнь и сентябрь 2026: экспертная разметка пользователя.
3. Февраль и апрель 2025: отдельная гипотеза влияния аномалий продаж на индекс; причинная связь с опубликованным индексом не установлена.

Без показателя рынка вариант с тремя dummy на более длинной истории даёт около 4,52% реального роста с 2027 года. Хьюбер и регуляризация проверены отдельно; в этих вариантах они не снизили дальний прогноз.

## Воспроизведение

Python 3.10+, из корня репозитория:

```bash
python -m pip install -r price_forecast/requirements.txt
python price_forecast/shock_normalization/full_history.py
python price_forecast/market_state/model.py
```

Код читает входные файлы относительно своей папки. Подготовленные продажи и срезы портфеля включены в `market_state/inputs/`; общий индекс цен и ИПЦ — в `inputs/monthly_data.csv`. Расчётные CSV и JSON находятся рядом с соответствующей моделью. Запуски обновляют результаты своих вариантов, исходные данные не изменяют.

Дополнительные проверки:

```bash
python price_forecast/shock_normalization/expert_wave.py
python price_forecast/shock_normalization/robustness.py
```
